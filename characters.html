Characters & Perksets

Each character has 5 alternative perksets. Each set unlocks starting at a certain character level for a Mycelium cost, and contains base perks, level-up perks, and optionally a unique trait.

Important – how perksets work in a run: Only ONE perkset is active per run (chosen before the run starts).
  • The base perks and the trait of the chosen set apply once at the start of the run.
  • The level-up perks of the chosen set, however, are automatically applied on every level-up in addition to the normal perk choice.
A perkset is therefore more of a build decision than a linear progression – the other 4 sets remain inactive for the run.
